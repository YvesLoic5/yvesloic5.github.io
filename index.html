Projet solo · A → Z

Multimodal RAG — Production-Grade

RAG complet texte + images : ingestion PDF/PNG/JPG, embeddings BGE-M3 (dense+sparse) & CLIP, Milvus hybride, génération GPT-4o en streaming avec fallback LLaVA.

détails techniques
  • Recherche hybride : HNSW cosine + BM25, fusion RRF
  • Reranking : Cross-Encoder MiniLM (top-20 → top-5)
  • Cache 2 niveaux Redis : exact (MD5) + sémantique (≥ 0.92)
  • Évaluation RAGAS sur 20 Q&A
  • Prod : Docker Compose, Tenacity, ingestion idempotente
