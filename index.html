Projet solo · de A à Z

Multimodal RAG — Production-Grade System

Système RAG complet supportant texte et images, construit de zéro. Pipeline d'ingestion (PDF/PNG/JPG/TXT → PyMuPDF/Pillow → chunks), embeddings dual (BGE-M3 dense+sparse pour le texte, CLIP pour les images), stockage vectoriel Milvus avec collection hybride (HNSW + SPARSE_INV), et génération LLM avec GPT-4o streaming + fallback LLaVA via Ollama.

Recherche hybride : Dense HNSW (cosine) + Sparse BM25, fusion RRF via pymilvus RRFRanker

Reranking : Cross-Encoder ms-marco-MiniLM-L-6-v2 (top-20 → top-5)

Cache 2 niveaux : Redis — exact (MD5, O(1)) + sémantique (cosine ≥ 0.92)

Évaluation : RAGAS (faithfulness, relevancy, recall, precision) sur 20 Q&A

Production : Docker Compose, Tenacity retries, singleton models, ingestion idempotente

University Advisor (Llama 2)

Bot d'orientation universitaire pour Madagascar, propulsé par Llama 2 7B Chat (quantisé GGML q4_0, exécuté en local). Indexation d'une base exhaustive d'institutions dans Pinecone, retrieval sémantique via LangChain, et interface web Flask.

Modèle local : Llama-2-7B-Chat GGML quantisé (q4_0), pas de dépendance cloud

Vector store : Pinecone pour l'indexation des établissements

Pipeline : store_index.py (indexation) → app.py (serveur Flask + chatbot)

Environnement : Conda, Python 3.8, déploiement local
